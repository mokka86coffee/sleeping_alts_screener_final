# Разбор лидеров: стадии хода (с 25.09)
Модель рынка — в памяти (market-model): 3 стадии рынка, фон (лидер, сессии, медиана/день недели), ММ; у хода начало → продолжение/подхват → конец и разворот; таймфреймы — только инструмент.
Файлы: rules.md — РЕЕСТР ПРАВИЛ со счётом совпадений (главный файл); moves.md — разбор каждого хода по стадиям; groups.md — ранние
наблюдения; notes.md — первичные заметки 1–30; anatomy.csv (+anatomy.py) — цифры ходов по 100 монетам; queue_31_100.json — окна графиков.
Метод на монету: 4h — где база, первый ход, откат, второй ход; 1h/15m — что было перед НАЧАЛОМ, на ПРОДОЛЖЕНИИ (кто подхватил, фандинг,
пузыри, топы), на КОНЦЕ; фон: день недели, сессия, общий слив доски/лидер. Запись: moves.md + счёт в rules.md (новое совпадение или новое R).
TradingView: chart_set_symbol BINANCE:<SYM>.P → sleep 6 → chart_set_timeframe → chart_set_visible_range дважды → screenshot. Окно TV — на экране.
Прогресс: см. последнюю строку moves.md. Папка перенесена в проект 26.09: claude/research/.
