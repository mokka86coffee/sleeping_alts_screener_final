# Патч · полоса времени в сводке

Три блока: два в `brief.py`, один в `css.py`.

Полоса уже есть и считает верно — `--lap` берётся из того же
`BRIEF_LAP`, что и таймер закрытия, так что расхождения между ней и
реальным моментом быть не может. Проблема в другом: включается она в
`tail()`, то есть после того, как допечатался весь текст. При
`BRIEF_LAP = 105000` и посимвольном наборе это большая часть ожидания,
и всё это время индикатора нет вовсе.

Плюс полоса не говорит, что будет в конце. «Экран уйдёт» и «дальше
покажут лидеров» — разные ожидания, и второе стоит назвать.

---

## Про дублирование стилей — не патчу намеренно

Блок стилей сводки в `css.py` присутствует **дважды**: строки
1320–1363 и 1783–1818. Отличаются они только шапкой — первый
начинается с `.ob-brief{position:fixed...}`, второго этого правила
нет, дальше идут одинаковые сорок строк, включая `.obf-bar`.

Править один из двух нельзя: они разъедутся, и разойдётся это молча.
Поэтому стиль новой подписи я кладу в блок орбиты-подиума, где
дубля нет. Само дублирование — отдельная правка, и её стоит сделать
осознанно, а не попутно.

# 1 · `render/brief.py` — подпись под полосой

### было

```python
    <div class="obf-bar" id="obfBar"><u></u></div>
```

### стало

```python
    <div class="obf-bar" id="obfBar"><u></u></div>
    <!-- Что будет, когда полоса кончится. Без этого полоса говорит
         только «экран уйдёт», а уходит он не в пустоту. -->
    <div class="obf-next" id="obfNext">дальше — лидеры прогона</div>
```

# 2 · `render/brief.py` — полоса видна сразу

Перенос из `tail()` в начало показа. Полоса отсчитывает время от
`requestAnimationFrame`, а видна была только с конца набора — то есть
показывала уже отыгранный остаток и в самый нужный момент отсутствовала.

### было

```python
    wrap.style.setProperty('--lap', (BRIEF_LAP / 1000) + 's');
    requestAnimationFrame(function () { wrap.classList.add('on'); });
```

### стало

```python
    wrap.style.setProperty('--lap', (BRIEF_LAP / 1000) + 's');
    requestAnimationFrame(function () { wrap.classList.add('on'); });

    /* Полоса и подпись включаются вместе с экраном, а не в tail().
       Отсчёт у полосы идёт от вставки элемента, то есть с этой самой
       строки; показывать её только после набора значило показывать
       уже отыгранный остаток — и не показывать ничего именно тогда,
       когда читатель гадает, сколько ещё ждать. */
    document.getElementById('obfBar').classList.add('on');
    var nx = document.getElementById('obfNext');
    if (nx) nx.classList.add('on');
```

### было

```python
      document.getElementById('obfFoot').classList.add('on');
      document.getElementById('obfBar').classList.add('on');
```

### стало

```python
      document.getElementById('obfFoot').classList.add('on');
```

# 3 · `render/css.py` — стиль подписи

Кладётся в блок экрана лидеров: там дубля нет. Соседство неочевидное,
но лучше, чем добавить сорок первую строку в один из двух одинаковых
блоков сводки.

### было

```css
.ob-podium{position:fixed;inset:0;z-index:41;display:flex;
```

### стало

```css
/* Подпись под полосой времени сводки. Живёт здесь, а не в блоке
   сводки, потому что тот в css.py продублирован целиком (строки
   1320–1363 и 1783–1818) — правка одного из двух разошлась бы с
   другим молча. */
.obf-next{margin-top:9px;text-align:center;font-size:7px;
  letter-spacing:3px;text-transform:uppercase;color:#2E2A24;
  opacity:0;transition:opacity .6s ease}
.obf-next.on{opacity:1}

.ob-podium{position:fixed;inset:0;z-index:41;display:flex;
```
