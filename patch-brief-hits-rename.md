# Ряды отбора читают hitCount

## файл: `render/brief.py`

Парный к `patch-orbit-hits-rename.md`: поле в звезде переименовано,
потому что имя `hits` в `coinCard` занято под список индексов.
Применять вместе с ним, иначе справка персистентности в рядах
покажет ноль у всех.

### было

```python
      var hist = (s.runsSeen || 0) > 0
        ? 'в лидерах <b>' + (s.hits || 0) + ' из ' + s.runsSeen +
          '</b> прогонов · ' + (s.days || 0) + ' дн в журнале'
        : '—';
```

### стало

```python
      var hist = (s.runsSeen || 0) > 0
        ? 'в лидерах <b>' + (s.hitCount || 0) + ' из ' + s.runsSeen +
          '</b> прогонов · ' + (s.days || 0) + ' дн в журнале'
        : '—';
```
