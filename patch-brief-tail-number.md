# Патч: пропавшее число в «плюс двадцати ушли N монет»

Ветка живого рынка (не frozen) собирает только словоформу
`plural(...)` («монет»/«монеты»), но не подставляет само число
`M.tail` перед ней — в отличие от ветки `frozen` чуть выше, где
число есть. Отсюда на скрине «плюс двадцати ушли монет» без цифры.

## файл: `render_brief.py`

### было
```javascript
         bg.push('Рынок <span class="gd">двигается</span>. Лучшая монета дня ' +
           '<span class="n">' + pct(M.maxChange, 0) + '</span>, дальше плюс ' +
           'двадцати ушли <span class="n">' + plural(M.tail || 0, 'монета', 'монеты', 'монет') + '</span> ' +
                                                                      ' — движение широкое, а не один выброс.');
```

### стало
```javascript
         bg.push('Рынок <span class="gd">двигается</span>. Лучшая монета дня ' +
           '<span class="n">' + pct(M.maxChange, 0) + '</span>, дальше плюс ' +
           'двадцати ушли <span class="n">' + (M.tail || 0) + '</span> ' +
           plural(M.tail || 0, 'монета', 'монеты', 'монет') +
           ' — движение широкое, а не один выброс.');
```
