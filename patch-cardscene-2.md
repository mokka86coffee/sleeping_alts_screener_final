# Карточка-пейзаж · правки после разбора по значениям

Все изменения в одном файле — `render/cardscene.py`. Подиум, дашборд и
стили не трогаются.

Что решено по ходу разбора и почему стоит именно так:

Объём остаётся максимумом из трёх окон, и окно рядом с числом не
подписывается. Всплеск и набор одинаково могут оказаться решающими,
а объём в любом случае одна из составляющих решения, а не оно само.

Левая дуга «объём к рекорду» остаётся как есть — она по-прежнему
повторяет высоту столба объёма, и это известное дублирование, а не
недосмотр.

## 1 · шапка: имя и стратегия вертикальным столбцом — `render/cardscene.py`

Рукописное имя на кегле в девяносто шесть пикселей занимало левую
половину кадра. На таком размере почерк перестаёт быть почерком и
становится пятном: места много, прочесть нечем.

Столбец у правого поля — форма подписи к свитку. Правая сторона
пустовала, вертикаль рифмуется со столбами света, а к берегу с
пагодой и соснами эта форма принадлежит по праву рождения. Тикер
набирается прямостоящими буквами и читается сразу; стратегия
остаётся росчерком, но в масштабе подписи, где почерк и работает.

### Было

```python
/* Имя написано крупно и почти в цвет неба, на полтона темнее.
   Так оно перестаёт спорить со столбами: читается вторым взглядом,
   как надпись на самом фоне, а не как подпись поверх картинки.
   Светлая кромка снизу вместо тени — буква получается вдавленной
   в фон, а не лежащей на нём. */
#obcRoot .bname{position:absolute;left:4.5%;top:14%;
  font-family:Caveat,'Segoe Script','Bradley Hand',cursive;
  font-size:clamp(34px,6.4vw,96px);font-weight:600;letter-spacing:.02em;
  line-height:.9;color:#11202D;transform:rotate(-3deg);
  /* мягкая широкая тень отделяет букву от неба, тонкая светлая
     кромка снизу оставляет её вдавленной, а не наклеенной */
  text-shadow:0 10px 26px rgba(0,0,0,.8),0 3px 8px rgba(0,0,0,.6),
    0 1.5px 0 rgba(160,205,240,.13),0 -1px 0 rgba(0,0,0,.55)}
```

## 7 · дни от дна · расчёт — `render/cardscene.py`

Считаем по сырому ряду цены, а не по выровненному: после приведения
к сетке шаг ряда уже не свой, а наш, и счёт съедет.

Допущение, которое стоит проверить: шаг ряда считается днём. Если
`series` четырёхчасовой или часовой — подпись врёт, и надо либо
делить на число баров в сутках, либо переименовать в бары.

### Было

```python
  var RIDGE_N = 28, HOURS_N = 24;
```

### Стало

```python
  var RIDGE_N = 28, HOURS_N = 24;

  /* Дни от дна. Считаем по сырому ряду цены, а не по выровненному:
     после resample шаг ряда уже не свой, а наш, и счёт съедет.
     Возвращаем число шагов от минимума до конца — при дневном ряде
     это и есть дни. Если минимум последний, ход ещё не начался. */
  function fromLow(c) {
    var s = (c.series || []).map(Number).filter(isFinite);
    if (s.length < 3) return null;
    var lo = 0;
    for (var i = 1; i < s.length; i++) if (s[i] < s[lo]) lo = i;
    return s.length - 1 - lo;
  }
```
