# Дельфины, фраза в два уровня и новая пагода

Все правки в `render/cardscene.py`, **поверх** второго, третьего и
четвёртого патчей. Пятый (`patch-cardscene-5-dolphins.md`) применять не
нужно — он устарел, здесь та же стая в исправленном виде.

Три независимых куска, их можно откатывать по отдельности: блоки 1–4 —
стая, 5–8 — фраза наблюдения, 9 — постройка на берегу.

## 1 · стая — стили и прыжок — `render/cardscene.py`

Прыжок разложен на три слоя: горизонтальный ход идёт ровно,
вертикаль выгибается дугой, тело доворачивается отдельно. В один
`transform` их не свести — у них разное течение времени.

Высота снята с настоящей параболы по девяти точкам, шаг между ними
ровный, сглаживания нет. Одна плавная кривая с замедлением к верху —
это движение планирующей птицы; у брошенного тела скорость падает
линейно, и вершина проскакивает почти мгновенно. Поворот по той же
причине идёт без сглаживания: касательная разворачивается быстрее
всего на вершине, там вертикальная скорость меняет знак.

Низ стаи стоит на 60.23% высоты кадра — это 530 из 880 внутренних
единиц, та же ватерлиния, что у лодки и у столбов.

## 5 · фраза наблюдения: два уровня вместо печати — `render/cardscene.py`

Фраза разламывается по смыслу: главное идёт крупно и в цвет,
остальное уходит в мелкую разрядку. Ломать есть по чему — зал уже
помечает ключевой кусок тегом, и до сих пор пометка только красила
его цветом; теперь она задаёт и размер.

Это же разводит фразу с приборной строкой внизу: у той один кегль на
всю длину, здесь два, и разница видна раньше, чем прочитано. Печать
больше не нужна — крупное слово само держит блок.

### Было

```python
/* Печать. Нижняя строка — это показания приборов: прописные,
   мелкие, разрядка. Наблюдение — единственная фраза в кадре,
   написанная человеческим языком, и набирать её тем же способом
   значит выдать вывод за очередное деление шкалы.

   Знак вместо буквицы взят потому, что фраза начинается с чего

   заглавная работала бы через раз, а печать стоит всегда одна и
   та же — и тем помечает не первую букву, а сам жанр записи.
```

## 7 · разбор фразы на уровни — `render/cardscene.py`

Если зал не пометил ключевой кусок, фраза остаётся одной строкой:
выдумывать, что в ней главное, модуль не станет.

### Было

```python
  var note = document.getElementById('obcNote');
```

### Стало

```python
  var note = document.getElementById('obcNote');

  /* Ключевой кусок зал помечает тегом b. Всё до него и после — мелкой
     разрядкой, сам он — крупно. Если пометки нет, фраза остаётся
     одной строкой: выдумывать, что в ней главное, мы не станем. */
  function levels(html) {
    if (!html) return '';
    var tmp = document.createElement('div');
    tmp.innerHTML = html;
    var b = tmp.querySelector('b');
    if (!b) return html;
    var before = '', after = '', seen = false;
    [].forEach.call(tmp.childNodes, function (n) {
      if (n === b) { seen = true; return; }
      if (seen) after += n.textContent; else before += n.textContent;
    });
    before = before.trim().replace(/[:,]\s*$/, '');
    after = after.trim();
    return (before ? '<span class="nq">' + before + '</span>' : '') +
           '<span class="nk ' + (b.className || '') + '">' + b.textContent + '</span>' +
           (after ? '<span class="nq">' + after + '</span>' : '');
  }
```

## 9 · пагода: пять ярусов, вогнутая кровля, окна по дуге — `render/cardscene.py`

Пагода узнаётся пропорцией и кровлей, а не числом этажей. Было три
яруса с почти прямыми навесами — выходила башня. Стало пять, каждый
заметно уже нижнего, и кровля с двойным изгибом: от конька провисает,
у концов задирается. Без этого любой навес читается козырьком.

Высота стены равна шагу между ярусами, поэтому низ каждой упирается
точно в верх нижней — прежде между ними был зазор в семь процентов
высоты, и этажи буквально висели. Сквозь постройку идёт столб от
земли до шпиля.

Окна: три проёма разной ширины, средний уже боковых. Башня круглая,
стена уходит по дуге, поэтому крайние сужаются по ракурсу и
разворачиваются вслед за поверхностью — прямой угол у всех трёх
сразу выдавал плоскую декорацию. Разворот выводится из положения
окна относительно центра, а не задан числом, и пересчитается сам при
любой смене ширины стены.

Свет только на двух нижних ярусах: наверху пагоды жилья нет.

### Было

```python
  function pagoda(g, x, base, hgt){
    g.fillStyle = '#04070A';
    const tiers = 3;
    for (let i = 0; i < tiers; i++){
      const w = hgt * (.62 - i * .13), y = base - hgt * (.18 + i * .27);
      // крыша: подтянутые вверх концы делает квадратичная кривая
      g.beginPath();
      g.moveTo(x - w/2, y);
      g.quadraticCurveTo(x, y - hgt*.10, x + w/2, y);
      g.quadraticCurveTo(x, y + hgt*.045, x - w/2, y);
      g.fill();
      g.fillRect(x - w*.28, y, w*.56, hgt*.20);
    }
    g.beginPath(); g.moveTo(x-1.4, base-hgt*.86); g.lineTo(x+1.4, base-hgt*.86);
    g.lineTo(x, base-hgt*1.06); g.closePath(); g.fill();
    g.fillRect(x - hgt*.20, base - hgt*.06, hgt*.40, hgt*.06);
    // окна — единственный тёплый свет в силуэте, он и делает
    // постройку обитаемой, а не вырезанной из бумаги
    g.fillStyle = 'rgba(255,132,50,.75)';
    for (let i = 0; i < tiers; i++){
      const y = base - hgt * (.18 + i*.27) + hgt*.05;
      for (let k = -1; k <= 1; k++) g.fillRect(x + k*hgt*.11 - 1.6, y, 3.2, hgt*.075);
    }
  }
```

```python
       Было три яруса с почти прямыми навесами — выходила башня.

    const T = 5, band = hgt * .118, y0 = base - hgt * .17;
    g.fillStyle = '#04070A';

    // синбасира — сквозной столб, на нём держится вся постройка
    g.fillRect(x - hgt * .035, base - hgt * .68, hgt * .07, hgt * .68);

    for (let i = 0; i < T; i++){
      const w  = hgt * (.52 - i * .068);   // размах кровли
      const ww = w * .44;                  // стена заметно уже: свес глубокий
      const yt = y0 - i * band;

      g.fillRect(x - ww / 2, yt, ww, band + 2);
      // галерея с перилами — то, что делает ярус этажом, а не полкой
      g.fillRect(x - ww * .78, yt + hgt * .020, ww * 1.56, hgt * .011);

      g.beginPath();
      g.moveTo(x - w / 2, yt - hgt * .030);
      g.bezierCurveTo(x - w * .30, yt - hgt * .004, x - w * .15, yt - hgt * .036,
                      x,           yt - hgt * .050);
      g.bezierCurveTo(x + w * .15, yt - hgt * .036, x + w * .30, yt - hgt * .004,
                      x + w / 2,   yt - hgt * .030);
      g.bezierCurveTo(x + w * .28, yt + hgt * .028, x + w * .12, yt + hgt * .014,
                      x,           yt + hgt * .012);
      g.bezierCurveTo(x - w * .12, yt + hgt * .014, x - w * .28, yt + hgt * .028,
                      x - w / 2,   yt - hgt * .030);
      g.closePath();
      g.fill();
    }

    // сорин: мачта с кольцами и шариком, растёт из столба
    const yTop = y0 - (T - 1) * band;
    g.fillRect(x - hgt * .007, base - hgt * .93, hgt * .014, yTop - (base - hgt * .93));
    for (let k = 0; k < 4; k++){
      const rw = hgt * (.048 - k * .010);
      g.fillRect(x - rw / 2, base - hgt * (.80 + k * .033), rw, hgt * .009);
    }
    g.beginPath(); g.arc(x, base - hgt * .945, hgt * .016, 0, 7); g.fill();

    // каменное основание в две ступени
    g.fillRect(x - hgt * .21, base - hgt * .048, hgt * .42, hgt * .034);
    g.fillRect(x - hgt * .27, base - hgt * .016, hgt * .54, hgt * .020);

    /* Свет только на двух нижних ярусах: наверху пагоды жилья нет,
       и ровный ряд огней до самой макушки выдал бы декорацию. */
    g.fillStyle = 'rgba(255,132,50,.75)';
    for (let i = 0; i < 2; i++){
      const w = hgt * (.52 - i * .068), ww = w * .44;
      const yt = y0 - i * band + hgt * .042;
      /* Три проёма разной ширины: средний уже боковых. Ровный ряд
         одинаковых прямоугольников выдаёт узор, а не постройку.

         Башня круглая, и стена уходит от нас по дуге. Значит,
         крайние окна мы видим не в лоб: они сужаются тем сильнее,
         чем ближе к краю, и разворачиваются вслед за поверхностью.
         Прямой угол у всех трёх сразу выдавал плоскую декорацию —
         рисованный фасад, приклеенный к цилиндру. */
      const wq = [.20, .13, .17], gap = ww * .15;
      let px = x - (ww * (wq[0] + wq[1] + wq[2]) + gap * 2) / 2;
      for (let k = 0; k < 3; k++){
        const w2 = ww * wq[k], cx = px + w2 / 2;
        const u = (cx - x) / (ww / 2);              // −1…1 вдоль стены
        const nar = Math.sqrt(Math.max(.2, 1 - u * u * .8));  // ракурс
        g.save();
        g.translate(cx, yt + hgt * .025);
        g.rotate(-u * .14);                         // разворот по дуге
        g.fillRect(-w2 * nar / 2, -hgt * .025, w2 * nar, hgt * .050);
        g.restore();
        px += w2 + gap;
      }
    }
  }
```
