# Фикс · подписи по несуществующим id — `render/cardscene.py`

`labels()` брала имя монеты и стратегию по идентификаторам `bname` и
`bstr`. Так они назывались в прототипе; при переносе в модуль все узлы
получили приставку `obc`, потому что на странице уже живут дашборд,
орбита и зал, и коротких имён там хватает своих.

Замену я делал по буквальному тексту `getElementById('bname')` — а здесь
идентификатор приходит переменной из массива, и под шаблон он не попал.
`getElementById` вернул `null`, `textContent` упал, и `open()` оборвался
до `requestAnimationFrame` — отсюда чёрный кадр при живой разметке:
лодка и строка наблюдения нарисованы разметкой, а холст просто ни разу
не отрисовался.

## Было

```js
    ['bname','bstr'].forEach((id, k) => {
```

## Стало

```js
    ['obcName','obcStr'].forEach((id, k) => {
```

Проверено на собранном модуле: из пятнадцати идентификаторов, по которым
обращается скрипт, все пятнадцать теперь есть в разметке.
