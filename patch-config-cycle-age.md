# Срок годности вершины

## файл: `detectors/flow_config.py`

Дельта к `patch-config-cycle-done.md`. Применять после него.

Отработанный ход перестаёт быть отработанным со временем. Вершина
годичной давности — не конец движения, а начало следующего: монета
успела упасть, отлежаться и построить базу заново, и судить её по
позапрошлому циклу нечем.

Срок применяется к обоим порогам, не только к среднему диапазону.
Монета, сделавшая ×25 год назад и с тех пор лежащая на дне, — это
определение спящего альта, а без срока она была бы забанена навсегда.
Свежие выносы при этом не спасаются: у TUT вершина пятидневная, он
выбывает в любом случае.

### было

```python
def cycle_done(up_x: float, peak_up_x: float) -> bool:
    """Отработала ли монета свой ход.

    up_x — где цена сейчас относительно дна цикла, peak_up_x — до
    какой высоты доходила. Обе в кратностях от одного дна.

    Ноль в любой из величин означает «не мерили», и тогда ответ
    отрицательный: выбрасывать монету по величине, которой нет,
    нельзя. Направление отказа выбрано намеренно — лишняя монета в
    списке стоит дешевле потерянной.
    """
    peak = max(float(peak_up_x or 0.0), float(up_x or 0.0))
    if peak <= 0:
        return False
```

### стало

```python
# Сколько дней вершина остаётся основанием считать ход отработанным.
#
# Дальше она перестаёт описывать текущее состояние монеты: за два
# месяца цена успевает найти новое дно, и старый пик относится уже к
# прошлому циклу. Замер 16 августа, 61 монета: пик окна старше
# шестидесяти дней у сорока пяти из них, медиана 104 дня, q75 — 200.
# Без отсечки правило судило бы рынок по позапрошлому движению.
#
# Совпадает с окном up_from_low в метриках: там «недавно» меряется
# тем же сроком.
CYCLE_PEAK_MAX_AGE_DAYS = 60


def cycle_done(up_x: float, peak_up_x: float,
               peak_age_days: float | None = None) -> bool:
    """Отработала ли монета свой ход.

    up_x — где цена сейчас относительно дна, peak_up_x — до какой
    высоты доходила, peak_age_days — сколько дней назад была та
    вершина. Первые две в кратностях от одного дна.

    Ноль в кратностях означает «не мерили», и тогда ответ
    отрицательный: выбрасывать монету по величине, которой нет,
    нельзя. То же с давностью: None — «не знаем, когда», и такая
    вершина правилом не считается вовсе. Направление отказа выбрано
    намеренно — лишняя монета в списке стоит дешевле потерянной.
    """
    # Срок годности проверяется ПЕРВЫМ, до порогов: устаревшая
    # вершина не описывает состояние монеты, и её величина уже
    # неважна. Отдельно поэтому и None не проходит: величина без
    # даты — то же самое, что величина неизвестной свежести.
    if peak_age_days is None or float(peak_age_days) < 0:
        return False
    if float(peak_age_days) > CYCLE_PEAK_MAX_AGE_DAYS:
        return False

    peak = max(float(peak_up_x or 0.0), float(up_x or 0.0))
    if peak <= 0:
        return False
```
