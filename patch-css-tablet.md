# Планшеты возвращают экран лидеров

## файл: `render/css.py`

Порог 900px снимал сцену и на планшетах: iPad в портрете это 768–834,
в альбоме 1024–1366. Половина устройств, где сцена читается прекрасно,
получала пустоту.

Новый порог — 760px, то есть телефоны. Между 760 и 900 сцена уже
раскладывается сеткой (медиазапрос в `podium.py`), так что планшет в
портрете получает не урезанный цилиндр, а плитку — форму, под которую
раскладка и писалась.

Блок `.ob-podium{display:none}` встречается в файле ДВАЖДЫ (следы
повторно применённых патчей — там же живут дубли анимаций, ради
которых заведён `fix_css_dedup.py`). Правятся оба: если поднять порог
в одном, второй продолжит прятать сцену, и это выглядело бы как
«патч не сработал».

### было

```python
/* На узком экране экран лидеров пропускается целиком, а не ужимается:
   половина сцены объясняет хуже, чем её отсутствие. Сводка при этом
   остаётся — это текст, он ничего не стоит. */
@media (max-width:900px){
  .ob-podium{display:none}
}

/* ── Экран лидеров ───────────────────────────────────────────
```

### стало

```python
/* Сцена снимается только на телефонах. На планшете она читается:
   в альбоме это полный цилиндр, в портрете — сетка панелей из
   медиазапроса podium.py. Порог 900 отрезал iPad целиком, хотя
   объяснять там нечего — места хватает. */
@media (max-width:760px){
  .ob-podium{display:none}
}

/* ── Экран лидеров ───────────────────────────────────────────
```

  .ob-podium{display:none}
