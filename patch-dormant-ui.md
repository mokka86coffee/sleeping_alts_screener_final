# 1 · `detectors/flow_config.py` — база скора

Прогон 14 августа: пятнадцать победителей, и четырнадцать из них
получили ровно **100**. Сырые скоры 66.1…92.0 при медиане 90.3.
Внутри полосы порядка нет — все монеты выглядят одинаково сильными.

Арифметика: база 44 умножается на шесть множителей — длительность до
1.35, плотность до 1.35, тишина 1.15, крупные покупки 1.25, поток 1.18,
пробуждение 1.30. Произведение доходит до четырёх, то есть 176, и всю
работу делает потолок `CAP_DORMANT = 92`. А `RAW_CEIL = 75` в сведении
отображает всё выше 75 в сотню.

Подкейс отвечал «фигура есть» и молчал о том, насколько.

### было

```python
DORMANT_SCORE_BASE = 44.0
```

### стало

```python
# Опущено с 44 после первого рабочего прогона. При 44 полный набор
# множителей давал 176 при потолке 92 — то есть скор определялся
# потолком, а не фигурой, и четырнадцать монет из пятнадцати
# получили одинаковые 100 после сведения.
#
# При 22 типовой набор ложится в 33…46, полный доходит до 88, и
# CAP_DORMANT возвращается к роли потолка вместо главного механизма.
DORMANT_SCORE_BASE = 22.0
```

# 2 · `render/dashboard.py` — узел на ленте стратегий

Спячка встаёт **первой**: лента читается слева направо как порядок
стадий, а спячка — единственное состояние до движения.

Координата 85 продолжает шаг ленты (124, 165, 221, 287, 335, 373 —
шаги 41, 56, 66, 48, 38), радиус взят между hidden и churn по числу
срабатываний. **Это единственное место, где я угадываю геометрию:**
cx пересчитаны из макета 1200×950 со сдвигом, и если узел вылезет за
левый край viewBox — правится одним числом.

### было

```python
FLOW_NODES = [
    ("hidden",   124, 22.0, "скрытый набор",        True),
```

### стало

```python
FLOW_NODES = [
    ("dormant",   85, 24.0, "спит после падения",   True),
    ("hidden",   124, 22.0, "скрытый набор",        True),
```

# 3 · `render/orbit.py` — палитра звёзд

Цвет холодный, как у всей стадии «у предполагаемого дна», но самый
приглушённый из трёх. Это не случайность: спящая звезда обязана быть
тусклее тех, где уже виден набор — цвет тогда несёт не только имя
подкейса, но и то, насколько далеко зашло.

### было

```js
  var STRAT = {
    hidden:   { c: '#7FE3D4', stage: 0 },
```

### стало

```js
  var STRAT = {
    dormant:  { c: '#7E9AB5', stage: 0 },
    hidden:   { c: '#7FE3D4', stage: 0 },
```

# 4 · Что уже на месте

`CASE_RU` во `flow_report.py` спячку знает — имя пришло туда первым
патчем и оттуда же попадает в чип карточки, легенду орбиты и подиум.
Второй список имён заводить не нужно.

`case_key()` снимает префикс `flow_`, поэтому счётчик на ленте найдёт
`dormant` без правок.

**Отдельно, не чиню:** узел плеча на ленте назван `"lever"`, а
`case_key` отдаёт `"leverage"` — счётчик у него всегда ноль. Подкейс
пока не срабатывает ни разу, поэтому вживую это незаметно, но
починится оно переименованием одной строки. Не трогаю в этом патче:
правка чужая по смыслу, и мешать её со спячкой значит терять её из
виду при откате.
