# Позиция в выборке FLOW и score

Правки в четырёх файлах: `render/flow_report.py`, `render/orbit.py`,
`render/podium.py`, `render/cardscene.py`.

На панелях зала у монет из текущего прогона появляется номер места и
score. В подвале карточки «в лидерах» заменяется на «в выборке».

Порядок мест берётся из одной функции — той же, что сортирует сам
список FLOW. Иначе номер на карточке и строка в списке разъедутся при
первой же правке правила.

---

## 1 · порядок списка FLOW вынесен в общую функцию — `render/flow_report.py`

Его теперь спрашивают в двух местах: сам список и подпись позиции на
карточке. Два независимых `sorted` разошлись бы при первой правке
правила сортировки, и номер на карточке перестал бы совпадать со
строкой в списке. Такое расхождение не падает и не логируется — его
замечают глазами через неделю.

### Было

```python
def render_flow_report(candidates: list[Candidate]) -> str:
    """Панель отчёта FLOW. Открывается кликом по ленте стратегии."""
    items = sorted(
        (c for c in candidates if c.flow),
        key=lambda c: -(getattr(c, "score", 0) or 0),
    )
```

### Стало

```python
def flow_order(candidates: list[Candidate]) -> list[Candidate]:
    """Монеты FLOW в порядке отчёта: по убыванию score.

    Порядок вынесен из render_flow_report, потому что его спрашивают
    уже в двух местах — сам список и подпись позиции на карточке. Два
    независимых sorted разошлись бы при первой правке правила, и номер
    на карточке перестал бы совпадать со строкой в списке. Такое
    расхождение не падает и не логируется — его замечают глазами через
    неделю.
    """
    return sorted(
        (c for c in candidates if c.flow),
        key=lambda c: -(getattr(c, "score", 0) or 0),
    )


def render_flow_report(candidates: list[Candidate]) -> str:
    """Панель отчёта FLOW. Открывается кликом по ленте стратегии."""
    items = flow_order(candidates)
```

### Было


### Стало

```python
    lead_sym = lead.symbol.upper() if lead is not None else ""
    by_symbol = {c.symbol.upper(): c for c in candidates}

    # Место монеты в текущем списке FLOW и размер этого списка.
    # Порядок берём у flow_order — той же функции, которой сортируется
    # сам отчёт, чтобы номер на карточке и строка в списке не разошлись.
    order = flow_order(candidates)
    fpos = {c.symbol.upper(): i + 1 for i, c in enumerate(order)}
    ftotal = len(order)
```

важнее, чем кажется: нулевой номер выглядел бы как первое место
наоборот, а отсутствие поля экран объяснит словами.

## 5 · стиль номера на панели зала — `render/podium.py`

Номер стоит в углу рамы и набран тише тикера: это не имя монеты, а
её место в очереди, и спорить с именем он не должен. Score под
номером ещё тише — он объясняет номер, а не существует сам по себе.

### Было

```python

```

### Стало

```python
.obp-note b.am{color:#FFC96B}
/* Место в текущем прогоне. Стоит в углу рамы и набрано тише тикера:
   это не имя монеты, а её номер в очереди, и спорить с именем он не
   должен. Score под номером ещё тише — он объясняет номер, а не
   существует сам по себе. */
.obp-rank{position:absolute;right:9px;top:8px;text-align:right;
```

## 7 · «в выборке» вместо «в лидерах» в подвале карточки — `render/cardscene.py`

«В лидерах 2 из 179» отвечает на вопрос «часто ли эта монета
всплывает». Вопрос хороший, и он никуда не делся: та же величина
стоит в нижнем ящике, в блоке за недели. В подвале полезнее другое —
где монета в этом прогоне и с каким score.

Монеты журнала вне текущей выборки говорят об этом прямо, а не
показывают прочерк: «нет» здесь означает «в этот прогон не попала»,
и это само по себе показание.

### Было

```python
    if (c.runsSeen) foot.push(['в лидерах', (c.hitCount || 0) + ' из ' + c.runsSeen, '']);
```

### Стало

```python
    /* Место в текущем прогоне вместо повторяемости. «В лидерах 2 из
       179» отвечает на вопрос «часто ли всплывает», и он никуда не
       делся — та же величина стоит в нижнем ящике, в блоке за недели.
       Здесь полезнее другое: где монета в этом прогоне и с каким
       score. Монеты журнала вне выборки говорят об этом прямо. */
    foot.push(['в выборке',
               c.fpos ? '№' + c.fpos + ' · ' + (num(c.score) || 0) : 'нет',
               '']);
```
