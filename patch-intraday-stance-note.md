# Пустой вердикт stance — норма, а не сбой

## файл: `analytics/intraday.py`

Требует, чтобы обновлённый `intraday.py` уже лежал в `analytics/`.

Правило, которое иначе переоткрывать через месяц: отсутствие вердикта
у `stance` на мёртвой базе — правильный ответ, и использовать его как
вето или как штраф нельзя. Комментарий ставится там, где вердикт
собирается, потому что читать его будет тот, кто придёт этот код
править.

### было

```python
    verdict = ""
    if buying and oi_up and (flat or down):
        verdict = "накопление"
```

### стало

```python
    # ── Пустой вердикт — это ОТВЕТ, а не отказ ──
    #
    # На мёртвой базе вердикта не будет, и так и должно быть. OI
    # меряет плечо; плечо приходит вместе с толпой, а толпа — после
    # начала движения. Накопление у дна в открытом интересе не видно
    # вовсе: оно идёт лимитами с крохотным нотионалом либо вообще не
    # на фьючерсе.
    #
    # BLESS, 5 июня: вход был, а OI в тот момент плоский и сползающий.
    # Разворот случился только в августе, через два месяца. Величина
    # не промолчала по ошибке — ей нечего было сказать.
    #
    # ПОЭТОМУ: не превращать отсутствие вердикта ни в вето, ни в
    # штраф, ни в множитель меньше единицы. Так выкосит ровно
    # дормантные фигуры — те, где OI обязан молчать, и где как раз
    # находится вход до толпы.
    #
    # Роли инструментов разведены, и путать их дорого:
    #   на базе ИЩУТ    — заметность крупной заявки (q), разворот
    #                     потока и вортекса; шумные по необходимости,
    #                     других на мёртвом обороте нет;
    #   в движении ПРОВЕРЯЮТ — эта тройка: реальный набор или вынос
    #                     закрывающихся. BLESS против BEAT.
    #
    # Иерархия доверия и иерархия полезности во времени — разные оси.
    # Самая надёжная величина оказывается самой поздней.
    verdict = ""
    if buying and oi_up and (flat or down):
        verdict = "накопление"
```
