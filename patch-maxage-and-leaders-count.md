# Срок журнала из конфига и снятие «в лидерах»

Две правки, обе — исправление, а не новая величина.

**Зашитая 14.** `LEADERS_MAX_AGE_DAYS` поднят до 26, но в разметке
число стояло литералом в трёх местах, и панель печатала «16 из 14» —
запись выглядела просроченной, хотя ей оставалось десять дней. Теперь
число подставляется из конфига при отрисовке, одним объявлением на
страницу; `podium` берёт его из `cardscene`, а не заводит своё, чтобы
история с двумя литералами на одно число не повторилась.

**«В лидерах» снято** из подвала карточки и из блока недельных
величин. Счётчик читался как оценка перспектив монеты, а перспектив
он не измеряет: будущее из частоты попаданий в выборку не следует.

Проверено: оба файла разбираются парсером, встроенный JavaScript
проходит `node --check`, якоря находятся по одному разу и после
применения не находятся.

Патчи писались по копиям от 01:32 — до применения снятия дублей и
патчей встряски. Все шесть якорей лежат вне тронутых теми патчами
мест, так что порядок применения значения не имеет.

## файл: `render/cardscene.py`

### было

```python
def render_cardscene() -> str:
    return CARDSCENE_CSS + CARDSCENE_HTML + CARDSCENE_JS
```

### стало

```python
from core.config import LEADERS_MAX_AGE_DAYS

# Срок жизни записи в журнале приходит из конфига, а не литералом в
# разметке. Прежде в JS стояла зашитая 14: после подъёма
# LEADERS_MAX_AGE_DAYS до 26 панель печатала «16 из 14», то есть
# запись выглядела просроченной, хотя ей оставалось десять дней.
# Число зашивается в страницу один раз при отрисовке.
MAX_AGE_JS = f'<script>var MAX_AGE_DAYS = {LEADERS_MAX_AGE_DAYS};</script>\n'


def render_cardscene() -> str:
    return CARDSCENE_CSS + CARDSCENE_HTML + MAX_AGE_JS + CARDSCENE_JS
```

### было

```javascript
        v: days + '/14', h: Math.min(1, days / 14) }
```

### стало

```javascript
        v: days + '/' + (+MAX_AGE_DAYS || 26),
        h: Math.min(1, days / (+MAX_AGE_DAYS || 26)) }
```

### было

```javascript
    if (c.runsSeen) foot.push(['в лидерах', (c.hitCount || 0) + ' из ' + c.runsSeen, '']);
    if (num(c.volBg) !== null) foot.push(['фон суток', '×' + xf(c.volBg), 'warm']);
```

### стало

```javascript
    /* «В лидерах» убрано намеренно. Счётчик показывал, сколько раз
       монета выходила в лидеры прогона, и читался как оценка её
       перспектив — а перспектив он не измеряет: будущее из частоты
       попаданий не следует. Настоящие иксы дают вещи, которых в наших
       данных нет, — сила сообщества и новости. Место в подвале дороже
       величины, которую нельзя применить. */
    if (num(c.volBg) !== null) foot.push(['фон суток', '×' + xf(c.volBg), 'warm']);
```
