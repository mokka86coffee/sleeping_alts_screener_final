# Часовой OI загружается до того, как понадобится

## файл: `analytics/metrics.py`

Дельта к `patch-metrics-oi-stance.md`. Применять после него.

Загрузка `oi_hourly` встала в блок «Деривативы», а он идёт НИЖЕ
вызова интрадея — строка 265 против 249. Отсюда
`UnboundLocalError: cannot access local variable 'oi_hourly'` на
первой же монете.

Ошибка из тех, что не ловится ничем, кроме запуска: синтаксис
валиден, модуль импортируется, а обход дерева считает переменную
объявленной, потому что присваивание в функции есть — просто позже.
Единственная проверка, которая её видит, это вызов функции целиком.

Загрузка переезжает к месту использования. Так она заодно стоит рядом
с тем, что объясняет, зачем нужна, и следующая правка порядка блоков
её не разъединит.

Заодно она заворачивается в try. Сквозной прогон `collect_metrics`
показал вторую вещь: при отказе загрузчика OI метрики падали целиком и
монета терялась. Ряд открытого интереса — обогащение, а не условие: без
него интрадей-слой просто не выставит вердикт, и это уже штатный
случай. Ронять из-за него всю монету не за что.

### было

```python
    # ── Деривативы ──
    # Часовой ряд открытого интереса. Нужен интрадей-слою, чтобы
    # различать набор и выход: у дельты и цены этого различия нет.
    # Вес запроса 1, кэш общий с остальными вызовами прогона.
    oi_hourly = [
        float(r.get("sumOpenInterest") or 0.0)
        for r in (get_oi_history(symbol, period="1h", limit=200) or [])
        if isinstance(r, dict)
    ]

    funding = get_funding_rate(symbol) * 100
```

### стало

```python
    # ── Деривативы ──
    funding = get_funding_rate(symbol) * 100
```

### было

```python
    # Часовые свечи плюс часовой ряд OI. Лестница шкал (2ч, 3ч, 6ч,
    # 12ч) складывается внутри из этих же часовых агрегацией — сети
    # на неё не нужно.
    intraday = intraday_scan(kl_1h, "1h", oi_hourly) if kl_1h else {}
```

### стало

```python
    # Часовой ряд открытого интереса. Нужен интрадей-слою, чтобы
    # различать набор и выход: у дельты и цены этого различия нет.
    # Вес запроса 1, кэш общий с остальными вызовами прогона.
    #
    # Загружается здесь, а не в блоке деривативов ниже: тот идёт
    # ПОСЛЕ этой строки, и переменная оказывалась использованной до
    # присваивания. Синтаксис при этом валиден и модуль импортируется,
    # так что видно такое только запуском.
    #
    # Отказ загрузчика гасится: ряд OI — обогащение, а не условие.
    # Без него интрадей-слой не выставит вердикт, и это штатный
    # случай; ронять из-за него всю монету не за что.
    try:
        oi_hourly = [
            float(r.get("sumOpenInterest") or 0.0)
            for r in (get_oi_history(symbol, period="1h", limit=200) or [])
            if isinstance(r, dict)
        ]
    except Exception:                                 # noqa: BLE001
        oi_hourly = []

    # Часовые свечи плюс часовой ряд OI. Лестница шкал (2ч, 3ч, 6ч,
    # 12ч) складывается внутри из этих же часовых агрегацией — сети
    # на неё не нужно.
    intraday = intraday_scan(kl_1h, "1h", oi_hourly) if kl_1h else {}
```
