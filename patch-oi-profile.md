# Движение плеча вместо его величины

Правка в `analytics/metrics.py`.

`oi_usd` считается верно — расхождение с TradingView оказалось
мнимым: индикатор для крипты рисует открытый интерес в базовой
монете, мы храним в долларах. У TREE 4.885M долларов при цене
0.04207 это ровно 116.1M токенов, то есть то же самое число.

Настоящая дыра в другом: у нас нет величины, отвечающей на вопрос
«набрали ли плечо и держат ли его». Часовой ряд OI уже грузится для
интрадей-слоя, но дальше него не идёт. Отсюда и вышло, что у TREE
`oi_x` показывал 1.03 при росте втрое за пять дней.

Новых сетевых запросов ноль.

## 1 · профиль открытого интереса — `analytics/metrics.py`

Величина OI сама по себе не значит ничего: миллион у одной монеты
много, у другой пыль. Значит её ДВИЖЕНИЕ, и различать надо два
противоположных состояния.

Плечо набрали и держат — толпа внутри, выход пойдёт каскадом. Плечо
набрали и оно сдулось — позиции закрыты, продавать сверху некому, и
это как раз топливо. Разбор ESPORTS показал второе в чистом виде:
памп начался ровно тогда, когда OI вернулся на дно.

Отсюда две величины вместо одной. `rise_x` — во сколько выросли от
минимума окна, `held_pct` — какая доля набранного удержана сейчас.
Сто процентов значит «стоим на пике», ноль — «всё вышло».

Считается из ряда, который уже загружен для интрадей-слоя: ни
одного нового запроса.

### Было

```python
BOTTOM_WINDOW = 60
```

### Стало

```python
# ── Профиль открытого интереса ─────────────────────────────
# Окно набора. Часовой ряд грузится на 200 точек — восемь суток.
# Набор плеча укладывается в этот срок: у TREE рост втрое занял
# пять дней, у GPS двое.
OI_WINDOW_H = 120


def oi_profile(oi_hourly: list[float]) -> dict:
    """Что случилось с открытым интересом за последние сутки-пять.

    Величина OI сама по себе не значит ничего: миллион у одной
    монеты много, у другой пыль. Значит её ДВИЖЕНИЕ, и различать надо
    два противоположных состояния.

    Плечо набрали и держат — толпа внутри, выход пойдёт каскадом.
    Плечо набрали и оно сдулось — позиции закрыты, продавать сверху
    некому, и это как раз топливо. Разбор ESPORTS показал второе в
    чистом виде: сильнейший памп начался ровно тогда, когда OI
    вернулся на дно.

    Отсюда две величины вместо одной. rise_x — во сколько раз выросли
    от минимума окна. held — какая доля набранного удержана сейчас,
    в процентах: сто означает «стоим на пике», ноль — «всё вышло».

    Пустой словарь, если ряда нет или он вырожден. Ноль соврал бы:
    отсутствие данных выглядело бы как отсутствие плеча.
    """
    row = [v for v in (oi_hourly or [])[-OI_WINDOW_H:] if v > 0]
    if len(row) < 12:
        return {}

    now = row[-1]
    lo, hi = min(row), max(row)
    if lo <= 0 or hi <= lo:
        return {}

    # Возраст пика в часах: свежий пик и пик недельной давности при
    # одинаковой высоте описывают разные рынки.
    peak_age_h = len(row) - 1 - max(range(len(row)), key=lambda i: row[i])

    return {
        "rise_x": round(now / lo, 2),
        "peak_x": round(hi / lo, 2),
        "held_pct": round((now - lo) / (hi - lo) * 100, 1),
        "peak_age_h": peak_age_h,
        "window_h": len(row),
    }


BOTTOM_WINDOW = 60
```
