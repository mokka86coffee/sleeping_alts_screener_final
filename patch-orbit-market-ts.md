# Патч: время прогона в market — поля не было вовсе

В `_orbit_market()` не было НИКАКОГО поля со временем прогона — не
опечатка в имени, а полное отсутствие. Брифинг поэтому был вынужден
брать `new Date()` — момент открытия страницы в браузере, а не момент
самого прогона, хотя комментарий в JS прямо говорит, что нужно
второе.

`snapshot.timestamp` уже существует и заполняется в run.py
(`RunSnapshot(timestamp=RunSnapshot.now_iso(), ...)`), просто никогда
не доходил до `window.ORB.market`.

## файл: `render_orbit.py`

### было
```python
    return {
        # «спокойный» и «осторожный» — пересказ режима, а не прогноз
        "calm": label.upper().replace("-", "").startswith("RISKON"),
        "appetite": f"{appetite}/5",
```

### стало
```python
    return {
        # Момент самого прогона, а не момент открытия страницы браузером.
        # Раньше этого поля не было вовсе ни под каким именем, и брифинг
        # был вынужден брать new Date() в JS — честная замена мёртвому
        # полю, а не опечатка в имени.
        "ts": str(getattr(snapshot, "timestamp", "") or ""),
        # «спокойный» и «осторожный» — пересказ режима, а не прогноз
        "calm": label.upper().replace("-", "").startswith("RISKON"),
        "appetite": f"{appetite}/5",
```
