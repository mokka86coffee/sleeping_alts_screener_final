# Зал: два ряда и панель в полтора раза крупнее

Правки в `render/podium.py`. Карточки-пейзажа не касаются.

Ряды перестали быть свойством яруса и стали свойством раскладки.
Раньше высот было ровно две, по числу стадий. Теперь ярус, который не
помещается в одну дугу, разворачивается в два ряда через один, а вся
стопка поднимается так, чтобы горизонт оказался посередине.

Что это даёт по числам, при радиусе 1400 и дуге в 340°:

| | было | стало |
|---|---|---|
| панель | 210 × 300 | 315 × 450 |
| шаг между соседями | 11.6° | 17.5° |
| помещается в один ряд | 30 | 20 |
| помещается в два ряда | — | 39 |

Вертикально: два ряда занимают 425 пикселей экрана, три — 642,
четыре — 858. Четыре ряда получаются только когда обе стадии
переполнены; если на твоём экране это окажется впритык, уменьшу шаг
между рядами или разрешу второй ряд только самой длинной стадии.

## 1 · панель в полтора раза больше — `render/podium.py`

210 × 300 становится 315 × 450. Отступы держат панель по центру
своей точки на стене, поэтому они меняются вместе с размером.

### Было

```python

```

### Стало


между соседями равна ширине с зазором. Одной правки ширины хватает,
