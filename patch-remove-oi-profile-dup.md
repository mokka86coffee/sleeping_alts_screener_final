# Патч: удаление мёртвого дубля OI-профиля (хвост Ч-1)

`analytics_metrics.oi_profile()` считала ту же идею, что теперь
живёт в `analytics_momentum.oi_cycle()` — другим окном (часовой ряд,
120 точек) и другой формулой `held_pct`. Результат клался в
`m["oi_prof"]` и доживал до `Candidate.raw["oi_prof"]` через
`strip_series()`, но ни один render-модуль это поле не читает —
проверено по всем `render_*.py`. Мёртвый код, не альтернатива:
если бы кто-то начал его читать, получил бы третье несовпадающее
число рядом с уже унифицированными `oiRise`/`oiHeld`.

## файл: `analytics_metrics.py`

### было
```python
# ── Профиль открытого интереса ─────────────────────────────
# Окно набора. Часовой ряд грузится на 200 точек — восемь суток.
# Набор плеча укладывается в этот срок: у TREE рост втрое занял
# пять дней, у GPS двое.
OI_WINDOW_H = 120


def oi_profile(oi_hourly: list[float]) -> dict:
    """Что случилось с открытым интересом за последние сутки-пять.

    Величина OI сама по себе не значит ничего: миллион у одной
    монеты много, у другой пыль. Значит её ДВИЖЕНИЕ, и различать надо
    два противоположных состояния.

    Плечо набрали и держат — толпа внутри, выход пойдёт каскадом.
    Плечо набрали и оно сдулось — позиции закрыты, продавать сверху
    некому, и это как раз топливо. Разбор ESPORTS показал второе в
    чистом виде: сильнейший памп начался ровно тогда, когда OI
    вернулся на дно.

    Отсюда две величины вместо одной. rise_x — во сколько раз выросли
    от минимума окна. held — какая доля набранного удержана сейчас,
    в процентах: сто означает «стоим на пике», ноль — «всё вышло».

    Пустой словарь, если ряда нет или он вырожден. Ноль соврал бы:
    отсутствие данных выглядело бы как отсутствие плеча.
    """
    row = [v for v in (oi_hourly or [])[-OI_WINDOW_H:] if v > 0]
    if len(row) < 12:
        return {}

    now = row[-1]
    lo, hi = min(row), max(row)
    if lo <= 0 or hi <= lo:
        return {}

    # Возраст пика в часах: свежий пик и пик недельной давности при
    # одинаковой высоте описывают разные рынки.
    peak_age_h = len(row) - 1 - max(range(len(row)), key=lambda i: row[i])

    return {
        "rise_x": round(now / lo, 2),
        "peak_x": round(hi / lo, 2),
        "held_pct": round((now - lo) / (hi - lo) * 100, 1),
        "peak_age_h": peak_age_h,
        "window_h": len(row),
    }


BOTTOM_WINDOW = 60
```
